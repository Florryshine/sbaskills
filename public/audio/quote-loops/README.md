# Quote-loop background music

Drop royalty-free instrumental `.mp3` files in this folder. The recorder
picks one at random per clip automatically — no code changes needed.

Where to get them:
- https://pixabay.com/music/ (same account as the image API keys — free,
  no attribution required)
- https://freesound.org/ as a backup

Search terms that work well: "upbeat instrumental", "corporate
motivational", "energetic loop", "cinematic hit". Filter to instrumental
only (no vocals) so they don't compete with the on-screen text.

Grab 6-10 tracks, any length or filename — the recorder trims to the
clip's actual recording window (~3-5s) automatically, you don't need to
cut them yourself.
