# Meme-loop laugh tracks / reaction sounds

Drop `.mp3` files here — the recorder picks one at random per clip
automatically, same as public/audio/quote-loops, just laugh/reaction
sounds instead of instrumental music. No code changes needed to add more.

Seeded with 4 tracks copied from public/audio/effects/ (the same laugh
clips used by the podcast engine) so this works out of the box. Add more
for variety — a single laugh track looping across every meme gets
repetitive fast.

Where to get more:
- https://freesound.org/ — search "crowd laugh", "audience laughter",
  "comedic sting", "wow reaction"
- https://pixabay.com/sound-effects/ — same account as the music API keys

Grab short clips (1-4s is plenty — the recorder trims to the clip's
actual recording window automatically) so the laugh lands right around
the punchline reveal instead of fading in halfway through.
